# Bundled 3dassets.dev models

These locally bundled environment models are CC0 1.0 Universal assets from [3dassets.dev](https://3dassets.dev/):

- [Pine Tree](https://3dassets.dev/assets/wipe-day-survival-island-pine-tree-dfc88d2b) — 132 triangles
- [Apple Tree](https://3dassets.dev/assets/medieval-mmo-starter-realm-apple-tree-ac43fca0) — 413 triangles

Attribution is not required by their CC0 licences. The models are stored locally to avoid a runtime network dependency.
